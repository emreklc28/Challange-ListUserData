# Challenge - List User Data

This is a simple mobile application built with React Native that fetches and displays a list of users from a public API. Users can view detailed information about each person by navigating to a detail screen.

## ✨ Features

- Fetches and displays a list of users from an external API.
- Tap on a user to view detailed information.
- Clean and minimal user interface.
- Navigation between list and detail screens.

## 🛠️ Technologies Used

- [React Native](https://reactnative.dev/)
- [React Navigation](https://reactnavigation.org/)
- [Axios](https://axios-http.com/) for HTTP requests
- [Random User API](https://randomuser.me/) as data source
